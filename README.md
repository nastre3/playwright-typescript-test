## README.md

# Playwright TypeScript Test Framework

Современный фреймворк для автоматизации тестирования веб-приложений с использованием Playwright и TypeScript.

## О проекте

Фреймворк предоставляет структурированное решение для автоматизации тестирования веб-приложений с поддержкой:
* Параллельного выполнения тестов
* Управления окружением
* Генерации отчетов
* Управления тестовыми данными

## Требования

* Node.js версии 16+
* TypeScript
* Playwright
* Git

## Установка

```bash
# Клонирование репозитория
git clone https://github.com/nastre70/playwright-typescript-test

# Установка зависимостей
npm install
```

## Структура проекта

```
playwright-typescript-test/
├── config/                # Конфигурационные файлы
├── pages/                 # Page Objects
├── tests/                 # Тестовые сценарии
├── utils/                 # Утилиты и помощники
├── .env.example           # Пример конфигурационного файла
├── package.json           # Зависимости проекта
└── tsconfig.json          # Конфигурация TypeScript
```

## Запуск тестов

```bash
# Запуск всех тестов
npm run test

# Запуск отдельного файла
npx playwright test tests/example.spec.ts

# Запуск в определенном браузере
npx playwright test --browser=chromium
```

## Отчеты

После выполнения тестов генерируются отчеты в формате:
* Allure
* HTML
* JUnit

## Конфигурация

Основные настройки находятся в файле `.env`:
* BROWSER_HEADLESS
* BASE_URL
* REPORT_DIR
* TIMEOUT

## Поддержка браузеров

Фреймворк поддерживает:
* Chromium
* Firefox
* WebKit
